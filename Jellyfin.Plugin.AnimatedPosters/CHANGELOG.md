# Animated Posters changelog

All notable changes to Animated Posters are recorded here. The newest version is at the top.
Jellyfin Medic, Medic Picks and Medic Profiles have their own changelogs.

## [1.0.0] – 2026-10-16

### Added
- First release. The library cards in **My Media** on the home screen fade slowly between random backdrops from each library, with a gentle pan and zoom and the title's logo when it has one. New ones are picked every 30 minutes.
- **Your own library art** can stay in the rotation every few slides, be blended over every image, or be replaced completely.
- **Hide the library names** under the cards, and **remove the card borders**, rounded corners and shadows.
- **Libraries to leave static**, one name per line, such as Live TV.
- Settings under **Plugins → Animated Posters**: seconds per image, crossfade length, how many items to pick from, how often to pick new ones, pan and zoom, and title logos.
- Works in the web browser and the desktop apps. The script is added to Jellyfin's web page as it's sent, and Jellyfin's own files are never changed.
